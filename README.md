# Soft Garden — p5.js Drawing Tool

Adapted from the provided ART 74 `your_drawing_tool_2026-2.zip` template. Uses its bundled p5.js library and preserves the 1–0 brush mapping, drawing loop, clear and save functions while redesigning all ten marks.

## Play
Open `index.html`, then select **Open drawing tool**. On GitHub Pages, enable Settings → Pages → Deploy from branch → main / (root).

## Brushes
1 Pencil, 2 Petal, 3 Leaf, 4 Grass, 5 Rain, 6 Sunshine, 7 Flower, 8 Cloud, 9 Dots, 0 Eraser. Hold mouse and drag. X clears; P saves PNG.

## Artist statement
Soft Garden makes small rhythms of nature visible through ten organic brushes. Its soft palette and repeated marks make garden scenes easy to sketch, but make technical drawings and precise portraits harder. These constraints are intentional artistic choices.

## Files
- `index.html` — landing page with concept and instructions
- `tool.html` — playable drawing instrument
- `your_drawing_tool_2026.js` — p5.js source
- `style.css` — presentation
- `libraries/p5.min.js` — p5.js library supplied with class template
